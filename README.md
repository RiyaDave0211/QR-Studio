# QR-Studio
A responsive QR Code Generator built with HTML, CSS and JavaScript. Generate QR codes for text, URLs, Wi-Fi and contact details with customizable colors and PNG download.

🚀 Features

🔐 User Registration and Login

📝 Generate QR codes from text

🌐 Convert website links into QR codes

📶 Generate Wi-Fi QR codes

👤 Create QR codes for phone numbers and email addresses

📄 Generate QR codes for file links and small text files

🎨 Customize QR code colors and background

📏 Adjust QR code size

⬇️ Download QR codes as PNG images

📋 Copy generated QR code images

🧹 Clear input fields and QR code preview

📱 Responsive design for desktop and mobile

✨ Modern pink-themed UI with glassmorphism effects

🛠️ Technologies Used

HTML5

CSS3

JavaScript

QRCode.js

LocalStorage

GitHub Pages

▶️ How to Use

Open the QR Studio website.

Register a new account or log in.

Select a QR code type: Text, Link, Wi-Fi, Contact, or File.

Enter the required information.

Customize the QR code color, background, and size.

Click Generate QR.

Download the QR code as a PNG image or copy it if your browser supports clipboard access.

Scan the QR code using a compatible device.
